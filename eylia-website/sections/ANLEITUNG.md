# ELURA – Startseiten-Sections (conversion-optimiert)

## So fügst du jede Section ein
1. Shopify-Admin → **Onlineshop → Themes** → bei Horizon **„Code bearbeiten"**
2. Ordner **`sections`** → **„Neue Datei hinzufügen"** → Name exakt wie unten (z. B. `elura-02-hero`) → Dateityp `.liquid`
3. Kompletten Inhalt der jeweiligen Datei reinkopieren → **Speichern**
4. Danach **„Anpassen" → Startseite → „Abschnitt hinzufügen"** → dort erscheint z. B. **„ELURA · Hero"** → hinzufügen
5. Reihenfolge per Drag & Drop wie unten anordnen

## Wichtig
- **Header & Footer** liefert dein Theme – nicht doppelt einbauen.
- Bei **Bestseller** im Editor eine **Collection auswählen** (z. B. „Flower" oder „Sale").
- Alle Texte, Bilder, Buttons, Farben sind im **„Anpassen"-Editor** editierbar.
- Collections sind schon angelegt: `flower`, `sale`, `armbander-1`, `halsketten`, `ringe`.
