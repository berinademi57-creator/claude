# Projekt-Anweisungen

## Websites bauen
Bei JEDER Website / Landingpage / Web-Seite / Web-Artifact immer diese Skills zusammen anwenden:

1. `ui-ux-pro-max` – zuerst: Stil, Farbpalette, Fonts, UX-Regeln über das Such-Script
   festlegen (`--design-system`), Pre-Delivery-Checkliste am Ende.
2. `design-system`, `ui-styling`, `brand`, `design` – Tokens, Komponenten-Styling
   (shadcn/Tailwind), Markenauftritt; `banner-design`/`slides` bei Bedarf.
3. `web-motion` – GSAP + ScrollTrigger, Lenis Smooth Scroll und React Bits für Bewegung.
4. Zusätzlich die übrigen passenden Skills (artifact-design, ademi-website-qa, design:*),
   nicht stattdessen.
